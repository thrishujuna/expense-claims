# Expense Claims Demo

A full-stack expense claims app with role-based dashboards for Staff, Manager, and Finance.

## Run locally

1. Install dependencies:
   npm install
2. Start the app in development mode:
   npm run dev
3. Open the frontend in the browser:
   http://localhost:5173

## Production build

1. Build frontend assets:
   npm run build
2. Start the Express server:
   npm run start
3. Open:
   http://localhost:5000

## Demo login

Use the user selector at the top of the page to switch identities. The backend enforces the role access restrictions.
